# Contributing to VibePanel

I welcome focused improvements. Please open an issue first when a change affects a physical panel or protocol behaviour.

- Keep the core shared by the desktop app and CLI.
- Do not add a monitor suite, network call, telemetry, or background service without a concrete reason.
- Mark unobserved hardware support as unverified.
- Do not copy GPL source code into this MIT repository.
- Keep pull requests small. I review the final change before it lands on `main`.
