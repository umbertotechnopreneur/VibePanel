# Vibe Panel

I'm [Umberto Giacobbi](https://umbertogiacobbi.biz). Vibe Panel puts music and Codex activity on a small USB screen.

I made it in a few days, on holiday. The software that came with my display frustrated me. Other open-source apps didn't suit me either. I learned from what their authors had shared and made my own. [Credit to their work](docs/protocol-notes.md#sources-studied).

It's still rough. I'm sharing it now because it may help someone.

**I still need to check memory use, speed and security.** I used AI to help write the code. I haven't had time to finish these checks. They are on my list, and I'll work on them when I can.

**Themes are Python programs. They run code on your PC. For now, only get them from [this official repository](https://github.com/umbertotechnopreneur/VibePanel). Security checks are still to do.**

For now, it runs on Windows. [How to use it](PORTABLE.md) · [What's left to do](cave.md).
