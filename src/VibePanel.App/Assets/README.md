# Product icon

The small icon is a two-color **VP** monogram. The 16, 24 and 32 px frames use `vibepanel-mark.svg`; larger frames use `vibepanel-app.svg`. Both are first-party vector drawings. The VibeWare initiative mark is separate and unchanged.

Run `scripts/Build-ProductIcon.py` with a Python/Skia runtime whose packages and extracted files have completed targeted Microsoft Defender scans. It writes the seven-frame Windows ICO and the 256 px PNG. Inspect the small frames on light and dark backgrounds after changes.
