# Product icon

The product icon is a small display with a sensor trace and two violet readings. The 16, 24 and 32 px frames use `thermalright-vibeware-mark.svg`; larger frames use `thermalright-vibeware-app.svg`. Both are first-party vector drawings, not Thermalright's logo. The VibeWare initiative mark is separate and unchanged.

Run `scripts/Build-ProductIcon.py` with a Python/Skia runtime whose packages and extracted files have completed targeted Microsoft Defender scans. It writes the seven-frame Windows ICO and the 256 px PNG. Inspect the small frames on light and dark backgrounds after changes.
